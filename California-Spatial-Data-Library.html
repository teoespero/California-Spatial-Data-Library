Inside the starter GeoPackage

Use these layers with the companion notebook to practice overlay, spatial joins, and mapping.

LayerCoverageGeometryUseful fields
ca_countiesCaliforniaPolygonsGEOID, NAME
ca_placesCalifornia incorporated places and census-designated placesPolygonsGEOID, NAME, NAMELSAD
monterey_tractsMonterey CountyPolygonsGEOID, TRACTCE
monterey_roadsMonterey CountyLinesLINEARID, FULLNAME, MTFCC
central_coast_earthquakesCentral Coast and nearby offshore watersPointsid, mag, depth_km, utc_time

The boundaries and roads come from 2024 Census TIGER/Line. Census attributes are preserved. Keep GEOIDs as text to preserve leading zeros. TIGER places include cities and census-designated places, and some cross county lines.

The earthquake layer uses this USGS catalog query. It covers 2015–2024 UTC, magnitude 2.5 or higher, 35.7–37.2° N and 123–120.2° W. Depth was moved from the point's Z coordinate into depth_km. The window includes offshore events, so some points will have no county match.

The GeoPackage stores all layers in WGS 84 (EPSG:4326). The notebook uses California Albers (EPSG:3310) for area and length. Source dates and coverage matter when combining layers.

Get started

You will need california-starter.gpkg and California-Spatial-Programming.ipynb from the starter package.

Colab and local Python setup

Google Colab

  1. Extract the starter ZIP and open California-Spatial-Programming.ipynb in Colab.
  2. In Colab's Files panel, upload california-starter.gpkg to the session's working folder.
  3. Run the notebook from top to bottom. If a package is missing, run %pip install geopandas matplotlib in a new cell, then rerun the exercise.

Local Python

Put the notebook and GeoPackage in the same folder. Open a terminal in that folder and run these commands.

python -m pip install geopandas matplotlib jupyterlab
python -m jupyterlab

Open the notebook in JupyterLab. To load your first layer from a Python session in that same folder, run this code.

import geopandas as gpd

counties = gpd.read_file("california-starter.gpkg", layer="ca_counties")
monterey = counties.loc[counties["GEOID"] == "06053"].to_crs(3310)
print(monterey[["GEOID", "NAME"]])

Make your work repeatable

For each layer you add, record the publisher, source URL, release date or query parameters, and the CRS. Keep the original download and write cleaned data to a separate file. In a notebook, show how you selected the study area so you can repeat the same steps for another county.
